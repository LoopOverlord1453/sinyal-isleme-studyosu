Ayrıntılı tanımlama

Taşımadan bağımsız, durumsuz SPTF v1 çerçeve üreticileri.

Bu fonksiyonlar ağ kullanmadan bir tampona tam çerçeve yazar. Kendi taşımanızı (UART köprüsü, SD kart kaydı …) kullanıyorsanız doğrudan bunları çağırın; UDP için UDP göndericisi katmanı her şeyi otomatik yapar.

DATA çerçevesi yazar.

samples, count örnek anının tüm kanallarını akışın yerleşiminde ve hedefin bellek düzeninde içerir: interleaved için count × channel_count ardışık eleman, planar için kanal başına count elemanlık bloklar.

Parametreler
[out]bufHedef tampon.
[in]capTampon kapasitesi (bayt).
[in]infoBaşlık alanları.
[in]cfgAkış yapılandırması.
[in]first_sampleİlk örneğin akış içi indeksi (kanal başına, < 2^62).
[in]samplesÖrnekler.
[in]countKanal başına örnek sayısı (≥ 1).
[out]out_lenYazılan bayt sayısı.
Döndürdüğü değerler
SPTF_OK,SPTF_ERR_ARG,SPTF_ERR_CONFIG,SPTF_ERR_SIZE

◆ sptf_crc32_update()

uint32_t sptf_crc32_update ( uint32_t crc,
const uint8_t * data,
size_t len )

CRC-32/ISO-HDLC'yi artımlı günceller.

Başlangıç değeri 0'dır: crc = sptf_crc32_update(0u, a, na); crc = sptf_crc32_update(crc, b, nb); Sonuç zlib crc32() ile aynıdır.

Parametreler
[in]crcÖnceki sonuç (ilk çağrıda 0).
[in]dataVeri.
[in]lenBayt sayısı.
Döndürdüğü değer
Güncellenmiş CRC.
