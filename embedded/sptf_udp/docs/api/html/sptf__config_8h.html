Makrolar

#define SPTF_CFG_CRC_TABLE   1
 CRC-32 desteği (1 = derlenir, 0 = derlenmez).
 
#define SPTF_CFG_CRC32_HOOK   my_hw_crc32
 İsteğe bağlı donanım CRC kancası.
 
#define SPTF_CFG_MAX_DATAGRAM   1472u
 Varsayılan en büyük UDP yükü (bayt). 1472 = Ethernet MTU 1500 − IPv4 (20) − UDP (8).
 
#define SPTF_CFG_DESCRIPTOR_PERIOD_MS   500u
 DESCRIPTOR tekrar periyodu (ms). Protokol en fazla 1000 ms ister; varsayılan yarısıdır.
 
#define SPTF_CFG_ASSERT(expr)
 Çalışma zamanı doğrulama makrosu. Varsayılan boştur; hata ayıklarken örn. assert bağlayın.
 
#define SPTF_CFG_HOST_BIG_ENDIAN   0
 Hedefin bayt sırası: 1 = büyük uçlu (big-endian), 0 = küçük uçlu.
 

Ayrıntılı tanımlama

SPTF-UDP kütüphanesinin derleme zamanı yapılandırması.

Varsayılanlar çoğu proje için uygundur. Değiştirmek için iki yol vardır:

  1. Derleyiciye makro verin: -DSPTF_CFG_CRC_TABLE=0
  2. Kendi başlığınızı yazın ve -DSPTF_USER_CONFIG_FILE="\"sptf_user_config.h\"" ile gösterin; o dosyadaki tanımlar buradaki varsayılanların yerine geçer.

sptf_config.h dosyasında tanımlanmıştır.
