Ayrıntılı tanımlama

BSD soket taşıma portu: lwIP socket API (FreeRTOS vb.), POSIX (Linux, Zephyr, embedded Linux) ve Windows (Winsock 2).

Seçim derleme zamanında yapılır:

  • SPTF_SOCKET_LWIP tanımlıysa lwip/sockets.h (LWIP_SOCKET = 1, LWIP_COMPAT_SOCKETS önerilir),
  • değilse _WIN32 tanımlıysa Winsock 2 (ws2_32 ile bağlayın),
  • aksi hâlde POSIX.

Datagram tamponu port nesnesinin içindedir (bir kopya: tampon → yığın). Soket varsayılan olarak bloklayan kipte açılır.
