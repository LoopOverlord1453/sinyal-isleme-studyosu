Ayrıntılı tanımlama

Akış yapılandırması.

Bir akıştaki tüm kanallar aynı tipte ve aynı hızdadır; farklı hız / tip için ayrı akış açın. channels dizisi kopyalanmaz: akış kullanıldığı sürece geçerli kalmalıdır (genelde static const).
