◆ sptf_status_t

enum sptf_status_t

Fonksiyon dönüş kodları. Başarı 0, hatalar negatiftir.

Enümeratör
SPTF_OK 

Başarılı.

SPTF_ERR_ARG 

NULL işaretçi ya da aralık dışı argüman.

SPTF_ERR_CONFIG 

Geçersiz akış / bağlantı yapılandırması.

SPTF_ERR_SIZE 

Çerçeve datagrama ya da tampona sığmıyor.

SPTF_ERR_NOMEM 

Taşıma katmanı tampon veremedi (ör. lwIP pbuf havuzu boş).

SPTF_ERR_IO 

Taşıma katmanı gönderemedi (ağ / sürücü hatası).

SPTF_ERR_BUSY 

Taşıma şu an meşgul, daha sonra yeniden denenebilir (EWOULDBLOCK).

SPTF_ERR_STATE 

Nesne başlatılmamış ya da bağlantıya ekli değil.

sptf.h dosyasının 72 numaralı satırında tanımlanmıştır.
