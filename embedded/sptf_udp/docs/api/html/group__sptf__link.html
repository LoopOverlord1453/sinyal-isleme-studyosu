Ayrıntılı tanımlama

Bağlantı (taşıma + saat) ve akış nesneleri.

Tipik kullanım:

static sptf_link_t link;
static sptf_stream_t adc;
static const sptf_channel_t ch[2] = { {"Ia", "A", 3.3 / 4096.0 / 0.1, 0.0}, {"Ib", "A", 3.3 / 4096.0 / 0.1, 0.0} };
static const sptf_stream_config_t adc_cfg = { 1u, "Motor akımları", 20000.0, SPTF_UINT16,
SPTF_LAYOUT_INTERLEAVED, 2u, ch, false };
sptf_link_config_t lc = { 0 };
sptf_lwip_raw_transport(&port, &lc.transport); // ya da sptf_socket_transport()
lc.clock = board_time_ns; // isteğe bağlı
(void)sptf_link_init(&link, &lc);
(void)sptf_stream_init(&adc, &link, &adc_cfg);
// DMA yarım / tam tamamlandığında (görev bağlamında):
(void)sptf_stream_write(&adc, half_buffer, 256u, SPTF_TS_AUTO);

◆ sptf_stream_init()

sptf_status_t sptf_stream_init ( sptf_stream_t * stream,
sptf_link_t * link,
const sptf_stream_config_t * cfg )

Akışı doğrular, bağlantıya ekler ve ilk DESCRIPTOR'ı sıraya koyar.

DESCRIPTOR, ilk sptf_stream_write ya da sptf_link_poll çağrısında gönderilir (ağ henüz hazır olmasa da başlatma başarılı olur). first_sample 0'dan, desc_rev 1'den başlar.

Parametreler
[out]streamAkış nesnesi (statik ya da kalıcı bellekte).
[in]linkBaşlatılmış bağlantı.
[in]cfgAkış yapılandırması (kopyalanır; kanal dizisi işaretçi olarak tutulur).
Döndürdüğü değerler
SPTF_OKBaşarılı.
SPTF_ERR_ARGNULL argüman ya da akış zaten bu bağlantıda.
SPTF_ERR_STATEBağlantı başlatılmamış.
SPTF_ERR_CONFIGYapılandırma geçersiz ya da aynı stream_id bağlantıda var.
SPTF_ERR_SIZEDESCRIPTOR ya da tek örnek anı max_datagram'a sığmıyor (1472 B'de en fazla 21 kanal; daha fazlası için jumbo çerçeve ya da akışları bölün).

◆ sptf_stream_write()

sptf_status_t sptf_stream_write ( sptf_stream_t * stream,
const void * samples,
uint32_t count,
uint64_t timestamp_ns )

Örnek bloğunu gönderir; gerekirse datagram boyutuna göre birden fazla DATA çerçevesine böler.

Önce DESCRIPTOR zamanı gelmişse (ilk çağrı, periyot doldu ya da yeniden yapılandırma) DESCRIPTOR gönderilir. Gönderilemeyen DATA çerçevelerinin örnekleri kayıp sayılır; first_sample yine ilerletilir ki alıcı zaman eksenini korusun ve boşluğu tam örnek sayısıyla göstersin.

Parametreler
[in,out]streamAkış.
[in]samplesAkışın yerleşiminde örnekler (bkz. sptf_encode_data); hedefin bellek düzeninde.
[in]countKanal başına örnek sayısı (≥ 1).
[in]timestamp_nsİlk örneğin zamanı (ns), SPTF_TS_NONE ya da SPTF_TS_AUTO.
Döndürdüğü değerler
SPTF_OKTüm çerçeveler gönderildi.
SPTF_ERR_ARG,SPTF_ERR_STATEGeçersiz çağrı (hiçbir şey gönderilmez, sayaç ilerlemez).
SPTF_ERR_NOMEM,SPTF_ERR_IO,SPTF_ERR_BUSYİlk başarısız gönderimin nedeni (kalan örnekler kayıp).
