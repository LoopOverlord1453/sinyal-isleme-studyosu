Ayrıntılı tanımlama

Kanal tanımı. Fiziksel değer = ham · scale + offset (karmaşıkta I ve Q'ya ayrı ayrı).

Örnek: 12 bit ADC, Vref = 3.3 V → scale = 3.3 / 4096.0, offset = 0.0, unit = "V".

sptf.h dosyasının 126 numaralı satırında tanımlanmıştır.
