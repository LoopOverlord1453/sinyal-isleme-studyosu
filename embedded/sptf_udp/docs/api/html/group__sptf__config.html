Makro Dokümantasyonu

◆ SPTF_CFG_CRC_TABLE

#define SPTF_CFG_CRC_TABLE   1

CRC-32 desteği (1 = derlenir, 0 = derlenmez).

UDP'nin kendi sağlama toplamı olduğu için CRC isteğe bağlıdır. 0 yapılırsa CRC isteyen akış yapılandırmaları SPTF_ERR_CONFIG ile reddedilir ve CRC kodu imaja girmez.

CRC-32 yöntemi: 1 = 256 girişli tablo (1 KiB flash, ~8 kat hızlı), 0 = bit bit (tablo yok).

sptf_config.h dosyasının 40 numaralı satırında tanımlanmıştır.

◆ SPTF_CFG_CRC32_HOOK

#define SPTF_CFG_CRC32_HOOK   my_hw_crc32

İsteğe bağlı donanım CRC kancası.

Tanımlanırsa kütüphane CRC'yi uint32_t SPTF_CFG_CRC32_HOOK(const uint8_t *data, size_t len) ile hesaplar. Fonksiyon CRC-32/ISO-HDLC sonucunu (yansıtılmış, init 0xFFFFFFFF, xorout 0xFFFFFFFF; kontrol değeri "123456789" → 0xCBF43926) döndürmelidir. Örnek: STM32 CRC birimi, giriş/çıkış ters çevirme açık.

sptf_config.h dosyasının 51 numaralı satırında tanımlanmıştır.

◆ SPTF_CFG_MAX_DATAGRAM

#define SPTF_CFG_MAX_DATAGRAM   1472u

Varsayılan en büyük UDP yükü (bayt). 1472 = Ethernet MTU 1500 − IPv4 (20) − UDP (8).

Bağlantı yapılandırmasında (sptf_link_config_t::max_datagram) akış başına daha küçük ya da jumbo çerçeve için daha büyük (en fazla 65507) bir değer verilebilir.

sptf_config.h dosyasının 61 numaralı satırında tanımlanmıştır.

◆ SPTF_CFG_HOST_BIG_ENDIAN

#define SPTF_CFG_HOST_BIG_ENDIAN   0

Hedefin bayt sırası: 1 = büyük uçlu (big-endian), 0 = küçük uçlu.

GCC / Clang'de __BYTE_ORDER__ ile otomatik bulunur; bulunamazsa küçük uçlu varsayılır (tüm Cortex-M, RISC-V, Xtensa ve x86 küçük uçludur). Büyük uçlu hedefte örnekler kabloya yazılırken bileşen bileşen çevrilir (kablo biçimi her zaman küçük uçludur).

sptf_config.h dosyasının 91 numaralı satırında tanımlanmıştır.
