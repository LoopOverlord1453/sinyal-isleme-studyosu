Fonksiyonlar

int sptf_app_init (void)
 Bağlantıyı, akışı ve ADC DMA'sını başlatır. MX_LWIP_Init()'ten sonra bir kez çağrılır.
 
void sptf_app_process (void)
 Ana döngüden sürekli çağrılır: hazır yarım tamponu gönderir, ~100 ms'de bir DESCRIPTOR zamanlamasını yürütür.
 

Ayrıntılı tanımlama

STM32 + lwIP (çıplak metal, NO_SYS = 1) örnek uygulaması: ADC DMA çift tamponu → SPTF-UDP.

STM32CubeMX projesine eklenir. Gerekenler:

  • LWIP etkin (NO_SYS = 1), MX_LWIP_Init() / MX_LWIP_Process() çağrılıyor.
  • ADC1: 2 kanal tarama, harici tetik (ör. TIM3 TRGO @ 20 kHz), DMA dairesel, yarım kelime (uint16).

Kullanım (main.c):

MX_LWIP_Init();
sptf_app_init();
while (1) {
MX_LWIP_Process();
sptf_app_process();
}
